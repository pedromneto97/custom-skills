# SeaORM v1 → v2 Migration Guide

> Most of the 1.x API still compiles in 2.x, so upgrade step by step: bump versions, fix the
> breaking items below, then adopt the new features (dense entities, COLUMN, loader) gradually.

## Toolchain & dependencies
| Area | v1 | v2 |
|------|----|----|
| Rust | edition 2021 | edition **2024**, MSRV **1.94** (`sea-orm-sync`: 1.88) |
| SeaQuery / SQLx | 0.32 / 0.8 | **1.0** / **0.9** |
| async-std runtime | supported | **deprecated** — move to tokio |
| Sync SQLite | — | `sea-orm-sync` crate (rusqlite) |

## Breaking changes to fix
| Area | v1 | v2 |
|------|----|----|
| `Expr` methods (`.eq`, `.add`, ...) | inherent | come from `ExprTrait` — add `use sea_orm::ExprTrait;` (not in `entity::prelude`) |
| `IntoCondition` | needed for `.into_condition()` | not needed — use `.into()` |
| `ConditionExpression` | exists | removed |
| `Alias::new("x")` | needed for string idens | `&'static str` works directly |
| `Iden::unquoted` | `fn unquoted(&self, s: &mut dyn Write)` | `fn unquoted(&self) -> &str` |
| `ConnectionTrait::execute / query_one / query_all / stream` | take `Statement` | take SeaQuery statements; raw `Statement` → `execute_raw` / `query_one_raw` / `query_all_raw` / `stream_raw` |
| `DatabaseConnection` | enum | struct wrapping `DatabaseConnectionType` — don't match on variants |
| `insert_many(..).exec` | `InsertResult`, empty input = error | `InsertManyResult` with `last_insert_id: Option<_>`; empty input = `Ok(InsertManyResult { last_insert_id: None })` |
| `on_empty_do_nothing()` / `Insert::do_nothing()` | required for empty / conflict | deprecated — use `try_insert()` / `on_conflict_do_nothing*()` |
| `exec_with_returning_many` | used for insert_many | deprecated — use `exec_with_returning` |
| `Update::one(..)` / `Delete::one(..)` with `.build()` | panics if PK `NotSet` | call `.validate()?` first → `DbErr::PrimaryKeyNotSet` |
| `delete_by_id` return type | `DeleteMany` | `ValidatedDeleteOne` |
| `exec_with_returning` on `delete_by_id` | `Vec<Model>` | `Option<Model>` |
| Postgres auto-increment PK | `serial` | `GENERATED BY DEFAULT AS IDENTITY` (feature `postgres-use-serial-pk` restores serial) |
| SQLite `Integer`/`BigInteger` | `integer` → `i32` | both → `integer`, codegen maps to `i64` (`--big-integer-type=i32` to keep `i32`) |
| SQLite `RETURNING` | opt-in | `sqlite-use-returning-for-3_35` on by default |
| MariaDB `RETURNING` | not supported | opt-in via `mariadb-use-returning` |
| `DeriveValueType` | not usable as PK | also derives `NotU8`, `IntoActiveValue`, `TryFromU64` — newtype PKs work; **delete manual impls** of these or you get conflicting-impl errors |
| `runtime-actix*` features | alias of tokio runtimes | removed — use `runtime-tokio-*` |
| `DeriveCustomColumn`, `default_as_str` | available | removed |
| Migrations | Postgres runs all in one batch txn | each migration wrapped individually; `use_transaction()` per migration |

## New in v2 (opt-in)
| Feature | How |
|---------|-----|
| Dense entity format | `#[sea_orm::model]` + `sea-orm-cli generate entity --entity-format dense` |
| Typed relation fields | `HasOne<E>`, `HasMany<E>`, `BelongsTo<E>` / `BelongsTo<Option<E>>` on `Model` |
| Type-safe columns | `COLUMN` constant (`cake::COLUMN.name.contains(..)`), compile-time checked |
| Unique-key helpers | `find_by_*` / `delete_by_*` for `#[sea_orm(unique)]`, `find_by_<key>` for `unique_key` |
| Entity Loader | `Entity::load().filter_by_*(..).with(Related).one(db)` → `ModelEx` |
| Nested ActiveModel | `ActiveModel::builder().set_x(..).add_y(..).save(db)`, `cascade_delete` |
| M-N `load_many` | junction entity argument not required |
| Postgres `= ANY` | `Column::eq_any(..)` / `ne_all(..)` |
| Entity-first workflow | features `schema-sync` + `entity-registry`, `db.get_schema_registry(..).sync(db)` |
| Raw SQL macro | `raw_sql!(Postgres, "... {var} ... ({..list})")` |
| `require_one` | non-optional `one()` returning `DbErr::RecordNotFound` |
| Async-closure txns | `db.transaction_async(async \|txn\| { .. })` |
